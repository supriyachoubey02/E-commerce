# My E-commerce Store

A basic e-commerce website built with node.js and mongo db  and JAVASCRIPT backend.

## Tech Stack

- JAVASCRIPT
- CSS
- EJS
  

## Getting Started

1. Clone the repository:

    git clone [https://github.com/supriyachoubey02/E-commerce.git](https://github.com/supriyachoubey02/E-commerce.git)

   Server is running on http://localhost:3000

2.Install dependencies:

     npm install
     npm install express mongoose body-parser cors express-session
     
3.Start the frontend:

     npm start
    

4.Database

      MONGODB database is used for storing products details.It will be connected to server by using "mongodb://localhost:27017/ecommerce"

5.Usage
    
    The website will open in your browser at http://localhost:3000. You can browse the available products.

6.Features

    Product listing
    Basic product details view
